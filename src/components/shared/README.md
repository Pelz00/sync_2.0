# components/shared

Cross-module composites built from `ui` primitives. Reused across feature modules.

Examples: `ListingCard` (deliberately reused across hostels/food/beauty/trades),
`VerifiedBadge`, `PriceTag`, `RatingStars`, `SearchBar`, `FilterPanel`,
`EmptyState`, `ErrorState`, `ModuleNav`, `MapPlaceholder`, etc.
